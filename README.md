## Features

| Tab | What it shows |
|-----|--------------|
| 📊 Dashboard | Weather KPIs, retail vs e-commerce revenue, live stream |
| 🛍 E-Commerce | GMV, platform split, category penetration, weather effect |
| 🏪 Retail Analysis | Footfall, margin waterfall, inventory risk, competitor bench |
| 📈 Live Trends | All 8 categories over time, rain/temp/AQI streams |
| 📅 30-Day Forecast | Prophet-style confidence bands, festival markers |
| 💬 Sentiment & UX | News feed, funnel, retention by weather condition |
| 🗺 All Cities | 7-city snapshot comparison |
| 💡 AI Insights | Feature importance, ML accuracy per category |
| 🤖 AI Chatbot | Memory-aware chat with voice read-aloud |
| 📡 Data Sources | OpenWeather · IBEF · IAMAI · DIPP · RBI · GDELT |

## Tech Stack

- **React 18** (UMD build via unpkg)
- **Recharts 2.8** (charts)
- **esbuild** — JSX pre-compiled at build time (zero browser compilation)
- No Webpack, no Vite, no Create React App — single `app.js` output

## Deployment

Deployed on **GitHub Pages** — static files only, no server needed.

## Local

Just open `index.html` directly in any modern browser. No `npm install` needed.
